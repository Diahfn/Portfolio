# Personal Portfolio — Diah Fitrianingrum

Four projects, one HTML file, zero frameworks. This repo holds the site itself, not a build pipeline pretending to be one.

**Live site:** https://diahfn.github.io/Portfolio/

## What's in here

- `index.html` — everything: case studies, skills breakdown, contact links
- `Diah-Fitrianingrum-CV.pdf` — the resume, in case scrolling isn't your thing

## Stack

Plain HTML, CSS, and JavaScript. No React, no bundler, no `node_modules` folder eating your disk.

The architecture diagrams (IBM ACE flows, Kong Gateway routing) are hand-built SVG, animated with CSS keyframes triggered on scroll. The theme toggle persists through LocalStorage. Both run on vanilla JS because the problem didn't need more than that.

## What it covers

- Where I work and what I actually build (enterprise middleware, API integration)
- Three real integration projects, each with the problem I hit, what I built, and the numbers that came out of it
- A skills breakdown by category instead of one giant tag cloud
- Ways to reach me

## Running it

Clone it, open `index.html`. That's the whole setup.
